FretLab 3.4.2 PWA (base funcional 3.4.1)

Envie o CONTEÚDO desta pasta para a raiz do repositório GitHub, mantendo index.html, manifest.webmanifest, service-worker.js e a pasta icons. Em Settings > Pages escolha Deploy from a branch, main, /(root). Abra o URL HTTPS no Chrome Android e use Instalar aplicação.

A captação do microfone exige permissão e testes no tablet. O histórico é guardado localmente pelo navegador; exporte dados antes de limpar armazenamento.
